# Mindo Tours hero content standard

Use this standard for English and Spanish hub, cluster and commercial landing pages. The goal is a consistent first screen without padding the page with filler copy.

## Content range

- Eyebrow: 2–5 words; maximum 32 characters.
- H1: 14–52 characters; normally 1–4 visual lines on desktop.
- Introduction: two short paragraphs; 420–560 total visible characters, including spaces.
- Actions: 2 primary decision links plus 1 optional WhatsApp link; maximum 3.
- Trust tags: 3–4 items; maximum 22 characters each; always one row. Short labels are preferred over scrolling.
- Image caption: 70–150 characters.

If the useful introduction is below the minimum, add one concrete planning fact: timing, transport, availability, audience or how the request is handled. Do not add generic destination language just to fill space. If the copy exceeds the maximum, move detail into the next section.

## Layout behavior

- On desktop, the hero image remains 560px tall. The copy column stretches to the full image-and-caption card height, and the CTA/tag group is anchored to its lower edge so both columns close on the same baseline. The image is cropped with `object-fit: cover`; it is never distorted.
- On tablet and mobile, the columns stack and use fixed 400px and 300px image crops respectively.
- Trust tags remain on one row. Pages should use short enough labels to fit at normal desktop widths; smaller screens may scroll the row horizontally.
